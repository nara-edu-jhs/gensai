# いまここ減災ナビ — Prototype 42

土地勘のない場所で、現在地から優先災害・地図・指定緊急避難場所を分かりやすく提示する静的Webアプリです。主画面は3領域に絞っています。

小学校低学年でも基本操作を追えることを基準に、日本語の主要な見出し・操作・災害名にルビを付け、大きな文字とボタン、番号による3段階の流れを採用しています。災害は最優先の1件だけを先に表示し、その他は必要な場合に開く構造です。

日本語表示では端末内のBIZ UDPゴシックを最優先し、利用できない場合は游ゴシック、ヒラギノ角ゴなどへ自動的に切り替えます。外部フォントを読み込まないため、オフライン利用にも影響しません。

Prototype 15では、災害を根拠なく順位づけして見せない表現へ変更しました。現在地の測位誤差と取得時刻、災害別の「まずすること」、避難候補の開設未確認表示を追加し、保存情報は取得時刻と現在地からの距離を確認してから再利用します。

Prototype 16では、画面の読み上げ、文字拡大、高コントラスト表示を追加しました。地図の番号と避難候補一覧を相互に移動でき、施設名・住所や係員に見せる文章をコピーできます。これらの操作は日本語・英語・中国語・韓国語に対応しています。

Prototype 17では、支援機能と指差し文を「みやすさ・ことば」の中へ収納しました。通常画面は、今すること、災害情報、地図、避難候補の流れだけが見える簡潔な構成です。カードの影と角丸も抑えています。

Prototype 18では、「現在地を調べる」「まずすること」「地図と避難場所」を別画面に分けました。GPSは高精度で失敗した場合に通常精度で再試行します。HTTPSでない開き方ではGPSが使えない理由を表示し、地図画像を取得できない場合は方向と距離の一覧へ案内します。

Prototype 19では、選択中の洪水・土砂災害・高潮・津波・内水氾濫の公開ハザード区域を、現在地と避難候補の地図へ重ねて表示できます。地震と大規模火災は静的区域として表示できないため、その旨を明示します。

Prototype 20では、地図の直下に災害別の凡例を表示します。洪水・高潮・津波は浸水深、内水氾濫は0.1m以上の浸水深、土砂災害は警戒区域と特別警戒区域を、色だけでなく文字でも説明します。想定区域であり現在の発生状況ではないことも明示します。

Prototype 28では、地図の上に「選んだ災害／土砂災害／色なし」の切替を追加しました。避難場所の対象災害を変えずに、土砂災害警戒区域を独立して重ねられます。黄色は警戒区域、赤色は特別警戒区域です。

Prototype 29では、曖昧だった「選んだ災害」を「洪水を重ねる」など実際の災害名に変更しました。区域図のない地震・大規模火災ではその旨を表示します。また、地図をマウス・指・矢印キーで移動でき、「現在地へ戻る」で元の表示へ戻せます。

Prototype 30では、旧版の地図部品が端末のキャッシュに残った場合に起動が止まる問題を修正しました。画面と各JavaScript部品を同じ版として読み直し、地図操作の初期化に問題があっても言語選択を妨げない構成にしています。

Prototype 31では、地図の周囲を従来より広く先読みし、ドラッグ中の画面更新を端末の描画タイミングに合わせました。素早く動かしたときの空白や引っかかりを減らしています。

Prototype 32では、地図画像のブラウザ標準ドラッグを無効化し、マウス・指の操作を地図移動として確実に受け取るよう修正しました。地図左上に拡大・縮小ボタンを追加し、広域までズームアウトできます。

Prototype 33では、地図に重ねる種類を「洪水・内水氾濫・高潮・津波・土砂災害・色なし」から明示的に選べるようにしました。全国統一の直接表示ができない「ため池・地震／液状化・火山」は、自治体が公開する公式ハザードマップへの入口として分けて表示します。

Prototype 34では、区域データが存在しない透明タイルや取得できなかったタイルが、壊れた画像の四角として残る問題を修正しました。読み込みに失敗した画像は即座に取り除きます。

Prototype 35では、ハザードレイヤーのプルダウンを、ルビと短い説明を持つラジオカードに変更しました。災害名だけでなく、何が起こる災害なのかを選択前に確認できます。日本語・英語・中国語・韓国語に対応します。

Prototype 36では、日本語画面の固定文と動的に追加される案内文へ、読みが確実な防災用語を中心に自動でルビを付けます。外部から取得する施設名・住所は誤読を避けるため原文を優先します。ハザード選択カードにはピクトグラム、説明、ラジオボタン、選択チェックを組み合わせ、色だけに依存しないデザインにしました。

Prototype 37では、不自然な改行を防ぐため、長いルビを「指定／緊急／避難／場所」のような意味の単位へ分割しました。日本語の禁則処理、見出しの行バランス、ルビ付き説明文の行間も調整しています。

Prototype 38では、手順カード内のルビ付き語がCSS Gridの別要素として配置され、文章が縦に分断される問題を修正しました。各手順の文章全体を1つの要素にまとめ、通常の横書きとして自然に折り返します。

Prototype 39では、日本語翻訳データ、災害別行動文、ボタン、状態表示、凡例を機械的に走査し、残っていた漢字の読みを追加しました。読みが地域で変わる施設名・住所・検索結果は誤読防止のため自動ルビ対象外です。

Prototype 40では、ZIP内のHTMLを直接開いたときにブラウザの安全制限でGPSが使えないことを画面内で明示し、場所検索・緯度経度入力・保存位置・東京駅サンプルをすぐ選べるようにしました。位置を選んだ後は外部データの取得を待たず、緯度・経度を直ちに表示します。GPSを使う場合はHTTPSで公開したページ、またはlocalhostから開いてください。

Prototype 41では、名称を「ここから防災」から「いまここ減災ナビ」へ変更しました。現在地を起点に、危険の確認、日頃の備え、避難先の選択を支援する目的が伝わる名称として、画面、ブラウザタイトル、各言語表示、説明文を統一しています。

Prototype 42では、「災害の区域を読み込めませんでした」などの状態表示をハザード選択ボタンと同じ横並びから外し、ボタン列の下に独立して表示します。文章の長さやルビの有無で選択ボタンの幅・高さが変わらないようにし、状態表示欄の高さも確保しています。

Prototype 21では、駅名・住所・建物名から場所を検索し、候補を確認してから地図と避難候補を表示できるようにしました。検索には国土地理院の住所検索を利用し、通信できない場合や検索に失敗した場合は公式地図への入口を表示します。

Prototype 22では、地震カードと避難候補一覧で使う国土地理院の指定緊急避難場所記号を、拡大してもぼやけないSVG版へ変更しました。図柄と配色は国土地理院配布の記号を基準にしています。

Prototype 23では、元画像のぼかしを引き継いでいたSVGを廃止し、中間色を含まない単色の輪郭データとして再作成しました。表示サイズや画面解像度が変わっても、ブラウザが輪郭を直接描画します。

Prototype 24では、ローカル表示で外部SVGを読み込めない環境があるため、記号をJavaScriptからページ内へ直接描画する方式に変更しました。画像ファイルの読み込みに依存せず、単色ベクターとして表示します。

Prototype 25では、ローカル表示時に古いJavaScriptやCSSがブラウザに残る問題を避けるため、読み込みURLへ版番号を付けました。地震記号は引き続きページ内に直接描画し、外部画像を使用しません。

Prototype 26では、推測で作ったベクター記号を廃止し、国土地理院が実際に配布している49×46pxの指定緊急避難場所記号へ戻しました。拡大による変形やぼけを避けるため、地震カードでは元の大きさのまま表示します。

Prototype 27では、内閣府が地方公共団体向けに公開しているJIS Z 9098データ集から、実際の標識に使われる避難場所図記号を150×150pxで抽出しました。形を推測・生成せず、72px表示へ縮小することで正確さと鮮明さを両立します。

最初に日本語・英語・中国語を大きな文字ボタンから選択します。災害と避難場所は、文字と標準図記号を併用して案内します。

災害種別には内閣府公開のJIS Z8210図記号データ、避難候補には国土地理院公開の指定緊急避難場所記号を使用します。絵文字は防災表示に使用していません。確認順は固定された縦並びと大きな順位番号で示します。この順位は公開ハザードタイルの簡易照合による「確認する順番」であり、被害規模の予測ではありません。

地震には全国共通のJIS災害種別一般図記号がないため、独自の地震図記号は使わず、国土地理院が公開する指定緊急避難場所記号を表示します。最初の言語選択画面は、日本語・English・中文の3ボタンだけを中心とする簡潔な構成です。

## 主な機能

- GPS、緯度経度の手入力、東京駅サンプル
- GPS地点と周辺約500mの公開ハザードデータを自動照合
- 「該当区域・周辺に区域・地点では未検出・確認できず」を区別
- 判定結果から優先災害を自動選択
- 現在地中心の地理院地図
- リスクカードの選択による災害切替
- 災害種別に対応する指定緊急避難場所の検索
- 距離、方向、住所、公式地図、徒歩ルート検索
- 日本語・英語・中国語・韓国語
- 車いす・ベビーカー・歩行困難に配慮した注意表示
- 公的ハザードマップへの導線
- Service Workerによるアプリ本体・表示済み地図タイルのオフラインキャッシュ
- 取得済みリスク、避難候補、最後の位置の端末保存
- オフライン表示、保存日時、最新情報ではない旨の警告

## ファイル構成

- `index.html` — 現在地入力と判断支援ダッシュボード
- `css/style.css` — 基本のレスポンシブデザイン
- `css/accessibility.css` — 言語選択画面とピクトグラム表示
- `js/app.js` — 画面、判断支援、避難候補、共有機能
- `js/boot.js` — 言語選択から位置選択画面への最低限の起動処理
- `js/i18n.js` — 日本語・英語・中国語
- `js/location.js` — GPS取得と例外処理
- `js/geo.js` — 地理院タイル、避難場所GeoJSON、距離・方向計算
- `js/hazard.js` — 公開ハザードタイルの地点・周辺照合と優先順位
- `js/offline.js` — 通信状態、保存済みデータ、Service Worker登録
- `service-worker.js` — アプリ本体と取得済み外部データのキャッシュ

## 公開

ビルドや追加ライブラリは不要です。このフォルダをGitHubリポジトリへ置き、GitHub Pagesで公開できます。GPSはHTTPSまたはlocalhostで動作します。地図と避難場所データの取得にはインターネット接続が必要です。

## データと安全上の注意

地図および指定緊急避難場所は国土地理院、災害区域の照合はハザードマップポータルサイトの公開データをリアルタイム取得します。自動照合は公開タイルの着色有無による簡易判定で、法的・専門的な危険度判定ではありません。掲載がないことは安全を意味せず、経路の通行可能性や施設の開設も保証しません。実災害時は自治体・気象庁・消防・警察・施設係員などの最新情報を優先してください。
